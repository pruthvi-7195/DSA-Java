# Recursion Basics

This folder contains beginner-level recursion problems that help in understanding recursive thinking and function calls.

## Problems Solved

| No. | Problem |
|------|----------|
| 1 | Sum of N Natural Numbers |
| 2 | Factorial Using Recursion |
| 3 | Fibonacci Using Recursion |

## Concepts Covered

- Base Case
- Recursive Calls
- Call Stack
- Mathematical Recurrence Relations

## Learning Outcomes

After completing these problems, I learned:

- How recursion works
- Importance of base conditions
- Breaking a problem into smaller subproblems
- Understanding recursive call flow

## Time Complexities

| Problem | Time Complexity |
|----------|----------------|
| Sum of N Natural Numbers | O(n) |
| Factorial | O(n) |
| Fibonacci (Recursive) | O(2ⁿ) |
