# Math for DSA


This folder contains basic mathematical and number theory problems frequently asked in coding interviews and placement tests.

## Problems Solved

| No. | Problem |
|------|----------|
| 1 | Armstrong Number |
| 2 | Prime Number Check |
| 3 | Prime Numbers from 1 to N (Sieve of Eratosthenes) |

## Concepts Covered

- Number Theory
- Digit Extraction
- Modulus Operator
- Prime Number Logic
- Square Root Optimization
- Sieve of Eratosthenes

## Learning Outcomes

After completing these problems, I learned:

- How to extract digits from a number
- How to check whether a number is prime efficiently
- How to generate prime numbers in a range
- Understanding the Sieve of Eratosthenes algorithm
- Time complexity optimization in mathematical problems

## Time Complexities

| Problem | Time Complexity |
|----------|----------------|
| Armstrong Number | O(d) |
| Prime Number Check | O(√n) |
| Sieve of Eratosthenes | O(n log log n) |
