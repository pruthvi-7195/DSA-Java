# Set and Distinct Problems

This folder contains problems solved using HashSet for duplicate detection, unique elements, and sequence tracking.

## Problems Solved

| No. | Problem |
|------|----------|
| 1 | Contains Duplicate |
| 2 | Intersection of Two Arrays (Distinct) |
| 3 | Longest Consecutive Sequence |

## Concepts Covered

- HashSet
- Duplicate Detection
- Distinct Elements
- Set Operations
- Consecutive Sequences
- O(1) Lookup

## Learning Outcomes

After completing these problems, I learned:

- Detecting duplicates efficiently
- Finding common distinct elements
- Using HashSet for sequence problems
- Solving array problems in O(n)

## Time Complexities

| Problem | Time Complexity |
|----------|----------------|
| Contains Duplicate | O(n) |
| Intersection of Two Arrays | O(n + m) |
| Longest Consecutive Sequence | O(n) |
