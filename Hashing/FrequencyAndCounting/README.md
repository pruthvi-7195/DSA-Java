# Frequency and Counting

This folder contains problems that use HashMap and HashSet for frequency counting and efficient lookups.

## Problems Solved

| No. | Problem |
|------|----------|
| 1 | Two Sum |
| 2 | Count Frequency of Each Element |
| 3 | Element with Maximum Frequency |

## Concepts Covered

- HashMap
- HashSet
- Frequency Counting
- Key-Value Storage
- Constant Time Lookup
- Duplicate Detection

## Learning Outcomes

After completing these problems, I learned:

- How HashMap stores frequencies
- Efficient searching using hashing
- Finding frequent elements
- Solving lookup problems in O(n)

## Time Complexities

| Problem | Time Complexity |
|----------|----------------|
| Two Sum | O(n) |
| Count Frequency of Each Element | O(n) |
| Element with Maximum Frequency | O(n) |
