# Arrays

This folder contains array-based Data Structures and Algorithms problems solved in Java.

Arrays are one of the most fundamental data structures and are frequently asked in coding interviews and placement tests.

## Topics Covered

### 1. Array Fundamentals
Basic operations and properties of arrays.

Problems:
- Largest Element in Array
- Second Largest Element in Array
- Check if Array is Sorted
- Sum of Array Elements
- Reverse an Array
- Linear Search
- Minimum and Maximum

### 2. Searching and Scanning
Problems involving finding elements and traversing arrays efficiently.
- Count Occurences of a number
- Check for Duplicates
- First Repeating Element
- Union of Two Arrays
- Merge Two Sorted Arrays 

### 3. Swap and Rearrange
- Missing number from 1 to N
- Left Rotate by One
- Left Rotate by K
- Segregate even and odd
- Segregate positive and negative
