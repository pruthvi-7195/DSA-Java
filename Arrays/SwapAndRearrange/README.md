# Swap and Rearrange

This folder contains problems involving element rearrangement, array rotations, and missing element detection.

## Problems Solved

| No. | Problem |
|------|----------|
| 1 | Missing Number from 1 to N |
| 2 | Left Rotate Array by One Position |
| 3 | Left Rotate Array by K Positions |

## Concepts Covered

- Array Rotation
- Rearrangement Techniques
- Mathematical Formula Approach
- Reversal Algorithm
- Modulo Operations

## Learning Outcomes

- Finding missing elements efficiently
- Performing array rotations
- Understanding cyclic shifts
- Optimizing array manipulation problems

## Time Complexities

| Problem | Time Complexity |
|----------|------------|
| Missing Number from 1 to N | O(n) |
| Left Rotate by One | O(n) |
| Left Rotate by K | O(n) |
