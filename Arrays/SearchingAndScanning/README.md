# Searching and Scanning

This folder contains problems that involve scanning arrays, searching for elements, and identifying patterns.

## Problems Solved

| No. | Problem | Difficulty |
|------|---------|------------|
| 1 | Count Occurrences of a Number | Easy |
| 2 | Check for Duplicates | Easy |
| 3 | First Repeating Element | Easy |
| 4 | Union of Two Arrays |
| 5 | Merge Two Sorted Arrays |

## Concepts Covered

- Linear Search
- Frequency Counting
- HashSet
- HashMap
- Union of Sets
- Two Pointer Technique
- Array Traversal

- Duplicate Detection

## Learning Outcomes

After completing these problems, I learned:

- How to search elements in arrays
- Counting occurrences efficiently
- Detecting duplicates using HashSet
- Finding repeating elements
- Understanding time-space tradeoffs

## Time Complexities

| Problem | Time Complexity |
|----------|----------------|
| Count Occurrences | O(n) |
| Check Duplicates | O(n) |
| First Repeating Element | O(n) |
| Union of Two Arrays | O(n + m) |
| Merge Two Sorted Arrays | O(n + m) |
